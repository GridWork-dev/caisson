# ADR-0377 — Module-schematics kickoff: hybrid direction + build locks (2026-07-22)

Status: accepted
Date: 2026-07-22

## Context

ADR-0376 lock 2 commissioned the module-schematics design kickoff
(`outputs/specs/module-schematics/SPEC.md`, CAISSON-145) for the 14 accepted
illustration-placeholder ledger rows. The kickoff opened with a research return per the
operator's direction-first fork answer: a refero reference pass (Trunk, Oxide, Timescale,
Checkly, Depot, Eraser, SST), a brand-floor read, and honest-architecture extraction from
the packages, delivered as rendered token-styled specimens in both themes (one blueprint
sheet of field-crypto's derivation flow + AEAD gate + envelope byte layout; one
cross-section of the Compliance bundle's members over the Apache-2.0 seam). Two baseline
facts surfaced by the research: the 14 surfaces are not blank (modules render one of 24
shared node-box SVG diagrams, bundles an icon-chip composition slide) — the kickoff
upgrades generic to bespoke; and the existing diagrams spend up to four concurrent accent
surfaces against the one-accent restraint every strong reference practices.

## Locks (operator picker, 2026-07-22 PM)

1. **Direction → C, HYBRID.** Blueprint linework sheets (stroke-only engineering-drawing
   register: port call-outs, dimension ticks, title blocks, grid paper) for the 11 module
   pages; cross-section strata (waterline, depth bands, depth gauge — the literal caisson)
   for the 3 bundle pages. Rationale accepted from the research: two vocabularies mapped
   to two content shapes (single mechanism vs composition-over-base) make the 14-page
   sameness risk lowest by construction rather than by per-page discipline; the cost is a
   second vocabulary amortized over only three pages.
2. **Cadence → system + 3 pilots, then review.** The schematic vocabulary + renderer land
   first, then three pilot pages (field-crypto — hard module; audit-worm — live-slide
   page; compliance — bundle) pause for operator review with screenshots before the
   remaining 11 render. (Locked at the kickoff-open picker, same sitting.)
3. **Live-slide pages → schematic + live slide.** audit-worm ChainViewer, ai-meter
   UsageChart, prompt-registry PromptBrowser, and local-store StoreSearch keep their live
   component; the schematic joins it. All 14 ledger rows close uniformly by re-audit after
   ship (ADR-0376 lock 2 verification clause unchanged).
4. **Accent tightening rides along.** Whichever pages the schematic pass touches, the
   existing diagrams' accent overspend (accent node + boundary + boundary head + chain
   link concurrently) tightens to one semantic accent element per diagram, per the
   ADR-0375 restraint — a repair inside the current system, not new accent spend.

## Constraints carried

Honest-artifact floor (ADR-0082/0237): every schematic depicts real architecture — real
seam, port, and function names from the packages; sample values visibly samples; drawn
subsets declared on-sheet. Theme-following from tokens only (no baked colors). No motion
on schematic art (reference-attested; DESIGN.md §7 reserves motion for real fail-closed
demos). Craft rules adopted from the reference synthesis: 1px structural / 1.5–2px flow
strokes, mono labels 8.5–11px, 3–5 primary nodes per 16:9 slot, framed never full-bleed,
one diagram to one claim.
