# Architecture decision records

Every design decision behind Caisson, one file per decision: `ADR-NNNN-slug.md`, numbered in the
order they were made. The records are append-only. A decided ADR is never edited; a later ADR
supersedes it and says so. The most recent is
[ADR-0428](ADR-0428-open-source-pivot.md), which made every package Apache-2.0 and ended the
commercial edition. The next record is ADR-0429.

These records were written while Caisson was a private, commercial product. Many of them link to
internal planning documents, trackers and deploy logs that were removed when the repository was
published; those links are intentionally dead. Prices, bundles, licensing tiers and hosted
services described in older records no longer exist, but the records stay as written so the
reasoning behind the code is preserved.
