# ADR-0234 — Ask-AI docs widget: seven fork locks, dual model lanes, day-one reach

**Status:** accepted · 2026-07-03 (fourth picker round, third sitting). Locks all seven forks of
`outputs/specs/ask-ai-widget/SPEC-ask-ai-widget.md` + the F2 spend-ceiling rider. Relates
ADR-0219 (CF front rate-limit), ADR-0105 (support-bot model env-swap), ADR-0196 (sitewide ⌘K),
ADR-0118 (Plausible). **Four picks are operator OVERRIDES of the tabled recommendation** (F2
dual-lane, F3 both placements, F4 expanded corpus, F5 Turnstile now). Append-only; supersede with
a later ADR, never edit.
**Tags:** `ai`, `frontend`, `ui`, `security`, `billing`.

## Decision

| Fork                     | Lock                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **F1 — auth posture**    | **Anonymous** — open to prospects; session presence relaxes limits, never required.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **F2 — model lanes**     | **OVERRIDE: TWO lanes, not one.** (a) **Public/anonymous site lane** — cheaper-but-good; default `google/gemini-3.5-flash` (research 2026-06: ~$0.16/M input, majors-grade grounding; `deepseek/deepseek-v4-flash` as the env-swap cheaper alternative). (b) **Premium authed/Discord lane** — default `anthropic/claude-sonnet-4.6`; this ALSO upgrades the support-bot's stale `anthropic/claude-3.5-sonnet` default (ADR-0105 env-swap, one config default bump). Both lanes env-swappable; model picks grounded in the 2026-06 OpenRouter landscape (aimadetools 2026-06-09 + digitalapplied 2026-06-03 roundups), any-model via the one OpenRouter key. |
| **F2 rider — spend cap** | **$10/day hard ceiling on the public lane**, fails closed to escalation (contact/Discord CTA). Raise on evidence only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **F3 — placement**       | **OVERRIDE: BOTH day one** — the docs-inline widget AND the ⌘K "Ask AI" tab ship together.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **F4 — corpus**          | **OVERRIDE: docs + marketing/pricing.** The `services/docs` corpus-pipeline expansion is IN scope for this program (its own task set). Pricing content must index from the pricebook/catalog source of truth, not scraped page text, so a cited price can never silently drift stale (the liability the tabled rec flagged).                                                                                                                                                                                                                                                                                                                                 |
| **F5 — abuse posture**   | **OVERRIDE: Cloudflare Turnstile gates `/api/ask` from day one** (invisible/managed), layered with the existing ADR-0219 CF edge rule and the F2 hard spend cap. The bespoke per-IP token bucket is the held-in-reserve escalation instead of Turnstile. CSP gains the Turnstile script/connect entries in the same change.                                                                                                                                                                                                                                                                                                                                  |
| **F6 — telemetry**       | **Plausible custom-event counts only** (opened/asked/answered/escalated) — no question text; capturing text stays a separate, separately-consented follow-up fork.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **F7 — synthesis home**  | **Port the RAG discipline to the site route** `apps/site/app/api/ask` (fenced untrusted context, INSUFFICIENT_CONTEXT sentinel, leak guard, token cap — from `services/support-bot` `rag.py`); `services/docs` stays a pure retrieval, non-browser, server-to-server contract.                                                                                                                                                                                                                                                                                                                                                                               |

## Consequences

- The build is unblocked; the SPEC's task list extends with: the ⌘K tab (F3), the Turnstile
  gate + CSP entries (F5), the corpus-pipeline expansion in `services/docs` (F4 — indexing
  marketing/pricing from source-of-truth data), the two-lane model config + the support-bot
  default bump (F2), and the $10/day fail-closed spend cap wired to the escalation CTA.
- `identity/security-surfaces.md` invariant: Turnstile adds a third-party script/connect
  surface on the site — the CSP change and any new sink row land in the same commit.
- EVAL fires at SHIP (the `ai` tag): grounding discipline (no-context → sentinel, no
  fabricated citations) must be exercised by tests on both lanes.
