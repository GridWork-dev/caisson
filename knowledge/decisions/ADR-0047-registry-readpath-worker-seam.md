# ADR-0047 — Registry read-path: static CI-built index + deferred Worker seam

Status: accepted · 2026-06-27 (Wave-0 shared-substrate session, Fork 4. The shape of how
`create-caisson` + the buyer MCP obtain the registry index, under ADR-0021/0004/0008.)

Fork 4 asked how consumers obtain the registry index. The operator chose a **read service /
Cloudflare Worker** over the static-file recommendation, then scoped Wave 0 to a **stub seam** —
the Worker is landed as a typed, tested function, not a deployed service.

## Decision

- **Source of truth: the static, CI-built `registry/index.json`.** It is regenerated by a single
  CI-only job from the git-tracked `registry/ledger.jsonl` version ledger (ADR-0021), git-tracked,
  and verified byte-identical to a fresh rebuild in CI (proving it is CI-built, not hand-edited).
- **Read API: `loadRegistryIndex` / `loadRegistryIndexFromFile` (parse-or-throw, never a cast).**
  The index **IS the generator allowlist** — `create-caisson` + the buyer MCP validate module
  **id + version** (`assertKnownModule` / `assertKnownVersion`) before any path/subprocess.
- **The Worker is a deferred seam, not a service.** A thin Cloudflare Worker read handler
  (`fetch`-handler signature + `wrangler.toml` + a typed read contract over the same parsed index)
  is landed and **unit-tested**, but **not deployed** — real edge serving + caching is P5/P6.
- **Entitlement filtering is OUT of Wave 0.** Knowing a module (allowlist) is distinct from being
  entitled to it (ADR-0008) — the entitlement gate is a separate request-time check the buyer MCP
  enforces at P6, never the read path. The Worker seam carries a documented `// P6:` entitlement
  hook, no logic.

## Rejected

- **Full entitlement-filtering read service now** — P6 commerce infra (auth + an entitlement store);
  over-built for a Wave-0 read path and overlaps the buyer-MCP work.
- **Live GitHub Packages API per generation** — couples generation to GH API rate limits (5k/hr) +
  per-call auth; the index abstraction exists to avoid this.
- **Static file as the _only_ artifact (no Worker at all)** — the original recommendation; the
  operator opted to stand up the Worker seam now so the serving path exists to grow into at P5/P6.

## Binding

The Wave-0 read path is the static CI-built `registry/index.json` parsed via
`loadRegistryIndex`/`loadRegistryIndexFromFile`; the index is the allowlist (id + version validated
before any path/subprocess); a thin Cloudflare Worker read handler ships as a unit-tested seam with
`wrangler.toml`, **not deployed**, with entitlement filtering deferred to ADR-0008/P6. Evidence:
ADR-0021; GitHub Docs "Working with the npm registry"; Cloudflare Pages/Workers private-package docs.
