`@caisson/ui` is the typed token floor and the styled component kit built on it. It ships a set of
`--cs-*` custom properties in **OKLCH**, delivered as exactly two themes — one light, one dark — plus
a catalog of components (Button, Card, Hero, Terminal, DataTable, and more) that read those tokens.
This docs site renders on those same tokens and components.

## The contract

You re-skin by **swapping token values**, never by forking a component. A component reads a token; it
never hard-codes a hex value, so a brand change is a set of new variables, not a patch across the
component tree.

```css
:root {
  --cs-bg: oklch(99% 0 0);
  --cs-fg: oklch(20% 0 0);
  --cs-accent: oklch(62% 0.19 256);
}

/* Re-skin = new values here. Components read the tokens; they never fork. */
```

<Callout type="info">
  The styled primitives ship today from `@caisson/ui/components` — Button, Card,
  Hero, Terminal, DataTable, and more. Every one reads the tokens above; re-skin
  by swapping token values, never by forking a component.
</Callout>
