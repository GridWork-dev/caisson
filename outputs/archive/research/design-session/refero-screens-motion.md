# Refero research — Product-screen + Motion/Interaction-flow (docs · dashboard · marketing motion)

**Session:** Design · Brand · SEO · Copy scope (`design/brand-site-seo`). **Surface owned by this artifact:**
product-screen patterns (docs-site, data-dense dashboard) + micro-interaction/motion flows. Feeds the
broader design system + the Fumadocs docs surface (themed onto `--cs-*` tokens, ADR-0045 fd-bridge in
`apps/site/app/global.css`).

**Brand floor it must obey (do not relitigate):** dark pro-tool aesthetic (specs/03 §1); cold-steel teal
accent `oklch(0.74 0.115 205)`, Hubot Sans + Martian Mono, `--cs-*` tokens (ADR-0042, `packages/ui/styles/tokens.css`);
evidence-forward voice, no AI-slop, no emoji, no exclamation in hero (specs/04). **Authority order**
(`identity/design-doctrine.md`): research **informs**, impeccable **executes**, brand floor **wins**.

> Method: `refero_search_screens` + `refero_search_flows` (platform `web`), pixel-level `refero_get_screen_image`
> on the load-bearing refs, plus one `refero_search_styles` pass for the dark-devtools visual lineage. Refs are
> cited by refero UUID / flow id + competitor URL. Forks are surfaced individually below; recommendations carry
> confidence + evidence and are **operator-gated** (never auto-decided, per CLAUDE.md operator rule).

## 2. Steal-list (≥5 concrete tactics per area)

**Docs:** (1) Resend's sticky right code-rail w/ persisted **language tabs default = TypeScript**; (2) The Org's
**always-dark request/response card** with `Copy / Expand all / Collapse all`; (3) Anthropic's **grouped sidebar +
scroll-spy "On this page"**; (4) inline `string` / `required`(red) **param type annotations**; (5) per-page
**"Was this helpful ✓/✗" + Prev/Next**; (6) Cursor's **"Ask AI" / copy-page affordance** for the AI-native angle.

**Dashboard:** (1) Mocha's **`-22`/`+20` color-coded ± ledger** (Date/Source/Ref/Δ); (2) Mercury's **pill filters +
mono amounts (cents superscript) + Failed badge + compact 40px rows**; (3) OpenAI/Anthropic **big-number balance +
auto-recharge toggle**; (4) Lovable's **per-project spend breakdown** → per-generation breakdown; (5) Resend's
**key reveal + copy** for the license card; (6) **avoid FlutterFlow's decorative empty-state** — go terse + command.

**Motion:** (1) Raycast's **hover-tooltip → checkmark** copy feedback; (2) Runey's **grouped ⌘K + footer hint bar +
result count**; (3) Resend's **gated action → inline success** (waitlist + send); (4) Linear/Warp **hover = tonal +
1px border brighten, no shadow-lift**; (5) **one fade-up-once** scroll primitive, reduced-motion → instant; (6) the
**artifact-is-the-hero** static code/CI-badge hero (SST/Resend), motion stays out of its way.
