# Design-manifest reference lock

Date: 2026-07-25

Scope: T5D generated component manifest and deterministic quality gates

## Primary reference

Refero style `c14c0a94-1037-449e-bf5b-4cb972656ac7` (shadcn UI): compact,
metadata-first component catalog; precise hierarchy; flat, functional presentation; no decorative
media competing with the component contract.

## Borrowed details

- Refero style `11d3e58a-87d7-4a9a-bbf5-720f4fd3ffc6` (Linear changelog): compact information
  hierarchy and restrained technical labeling.
- Refero style `d500b995-352a-4a4f-8016-cb00cdb6eb17` (Convex): code-first artifact framing and
  explicit implementation detail.

## Preserve

- Caisson's existing cold-steel tokens, Hubot Sans/Martian Mono type roles, component APIs, recipe,
  and accessibility behavior.
- One authoritative component barrel and generated metadata, with dense machine-readable detail.
- Exact, quiet hierarchy: names, props, variants, token dependencies, accessibility notes, and
  recipe rules before prose.

## Reject

- No new colors, typefaces, radii, shadows, layout, icons, illustrations, or motion.
- No visual redesign and no existing site-copy change.
- No hand-maintained 39-row inventory or generic metadata placeholders.
- No averaging the three references into a new visual direction.

## Implementation consequence

This is a code-native metadata slice. The references lock the information architecture and density,
while the generated JSON and drift guard are the output; no UI pixels change.
