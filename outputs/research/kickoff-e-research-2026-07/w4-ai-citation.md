## 3. Hand-rolled probe loop — cost math, fidelity, infra

**Cost.** Per-call blended estimate (500 in / 800 out tokens, one web-search round):

- Claude Sonnet 5 + native `web_search` tool: ~$0.0015+$0.012 tokens + $10/1k-call search fee (Anthropic pricing, verified via `claude-api` skill) ≈ **$0.024/call**
- GPT-5 + `web_search` tool: $10/1k calls (reasoning models) + token cost ≈ **$0.019/call**
- Perplexity Sonar Pro (inherently web-grounded, no separate search tool): $3/$15 per MTok + $6–14/1k request fee ≈ **$0.024/call** (docs.perplexity.ai/docs/sonar, verified)

18 questions × 3 engines (Claude/GPT/Perplexity — Gemini-the-model addable as a 4th, AI Overviews not API-reachable) ≈ 54 calls/run × ~$0.022 ≈ **$1.20/run**.

| Cadence | Runs/mo | Cost/mo |
| ------- | ------- | ------- |
| Weekly  | 4.33    | ~$5.20  |
| Monthly | 1       | ~$1.20  |

Token spend is trivially cheap at this scale — **the real cost is engineering + maintenance time, not API dollars.**

**Doctrine constraint (binding).** Per `identity/doctrine.md`, all cross-vendor LLM work routes through **PAL → OpenRouter**, the single external LLM credential — direct OpenAI/Anthropic/Perplexity API keys are out of scope for this repo's trust boundary. PAL itself is a session-time MCP tool and cannot be invoked from an unattended systemd/cron oneshot; the correct unattended-job pattern (same one `gridwork-dream-llm.service` and `exa-monitors.ts` already use) is calling **OpenRouter's REST API directly** with `OPENROUTER_API_KEY` — same sanctioned egress sink, just bypassing the MCP wrapper for a background job. OpenRouter aliases (`openai/gpt-5`, `anthropic/claude-sonnet-5`, `perplexity/sonar-pro`) generally pass through underlying provider token pricing with little/no markup, so the cost table above should hold within a small margin — **verify OpenRouter's exact per-model rate at implementation time**, this wasn't independently re-verified here.

**Fidelity ceiling (honest limit, and the whole reason paid tools exist).** API answers are NOT the consumer-app experience: no ChatGPT memory/browsing-by-default, no Perplexity app UI ranking, no ambient personalization, and critically **no Google AI Overviews access at all** (SERP-feature-only, not an API). A DIY loop measures "does the raw model, given search-tool access, mention Caisson" — a real and useful signal, but a narrower one than what Peec/Ahrefs/Profound sell. Treat the DIY loop as a **cheap, high-frequency trend signal**, not a replacement for periodic ground-truth from a paid tool.

**Infra precedent.** `system/systemd/gridwork-exa-monitors.timer` + `.service` (30-min poller) and `gridwork-dream.timer` + `.service` (nightly oneshot) are the exact reusable pattern: `Type=oneshot`, sanitized-env-mirror `EnvironmentFile`, `pg_isready` boot-race gate, `bun run <script>.ts`. A `gridwork-caisson-aeo-probe.timer/.service` pair on the same box, gated on `gridwork-postgres-events.service`, is a same-shape addition — or, since caisson already runs CI on `caisson-amd64` self-hosted runners, a **GitHub Actions scheduled workflow** (`schedule: cron`) is the lighter-weight option that needs no host-level systemd unit and lives in-repo under version control. Recommend GitHub Actions — caisson's CI/deploy story is already GitHub-Actions-centric (`identity/ci-patterns.md`), and this avoids adding a new gridwork-core host dependency for a caisson-specific job.

## 6. Recommendation

**Ship the DIY OpenRouter-routed probe loop now (monthly cadence, ~$1.20/mo in tokens), writing to both `docs/gtm/aeo-citation-tracking.md` and a PostHog custom event — skip every paid tool until real launch traffic exists.** Confidence: **high** — gap #9's own disposition explicitly defers a paid tracker to "when launch traffic exists to measure" (`gaps-and-plays.md`), and at pre-launch volume a $189–495/mo tool buys negligible signal over an ~$1–5/mo scripted loop hitting the same three engines through the one already-sanctioned OpenRouter credential.

**When real traffic exists, add Otterly.ai Standard ($189/mo)** as the paid ground-truth layer — not Peec (opaque engine-count gating behind add-on pricing) or Ahrefs Brand Radar (requires an existing $129+/mo Ahrefs subscription, worst cost-per-signal in the set at $828+/mo for full coverage) or Profound (Starter tier is functionally unusable — no exports, ChatGPT-only). Confidence: **medium** — Otterly's REST API + MCP server at the $189 tier is the best fit for wiring into `gw-aeo-strategist`'s existing PAL/exa-based workflow without adding a second credentialed surface, but this recommendation should be re-priced against live traffic numbers once launch data exists, not locked now.

**Monthly budget number: $0 pre-launch beyond token spend (~$1.20–5/mo); $189/mo the month real launch traffic starts.**
