## Scripts

- `bun install` — install the `@caisson-sh/*` modules you composed in, plus Next/React.
- `bun run dev` — start the dev server.
- `bun run build` — production build (typechecks as part of the build).
- `bun run start` — serve the production build.
- `bun run lint` — oxlint.
- `bun run test` — unit tests + golden-file regression for the installed modules.

## CI

`.github/workflows/ci.yml` runs `build`, `lint`, `unit`, and `golden` on every push and pull
request. This is your repo — extend it freely.
