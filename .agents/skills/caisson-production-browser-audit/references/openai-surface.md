# Codex browser surface

- Use the Codex app built-in Browser for public navigation, clicks, typing, screenshots, and rendered-state inspection.
- Use Computer Use through a dedicated Chrome profile for authenticated buyer/admin rings. Dedicated profiles preserve auth separation and reduce accidental personal-session use.
- Use GPT-5.6 for screenshot understanding and interaction. GPT-5.3-Codex-Spark is text-only and cannot own visual verdicts.
- Use CDP as a scoped evidence aid, not as a second automation harness or permission expansion.
- Do not build a Responses API browser runner in this lane. The browser agent drives the real site; deterministic scripts only prepare and validate artifacts.
