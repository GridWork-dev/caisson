# Design rubric

Evaluate the system, not isolated prettiness:

Apply the register by ring: public marketing uses Impeccable `brand` permissions (distinctive composition, art direction, authored first-load motion); buyer/admin use `product` discipline (earned familiarity, fixed type scale, restrained state-rich color, structural responsiveness, consistent controls, short state-conveying motion). Identity and Caisson token roles stay constant across both.

- Hierarchy: one clear primary action and intentional scan path; progressive disclosure controls density.
- Typography: Caisson type roles, readable measures, real hierarchy, stable wrapping, no generic dashboard sameness.
- Color: accent has a semantic job; status never depends on color alone; contrast survives both themes.
- Layout: deliberate alignment, rhythm, density, edge treatment, and responsive recomposition rather than shrinkage.
- Depth: Caisson atmosphere and elevation clarify layers without decorative fog or excess glow.
- Motion: authored state transitions, focus/meaning preservation, reduced-motion equivalence, no gratuitous choreography.
- Components: coherent tokens and interaction patterns across marketing, buyer, and admin without flattening their different jobs.
- Copy: labels predict the next action; claims are true-to-built; errors name recovery; no vague AI/product filler.
- States: loading, empty, success, partial, error, disabled, denied, and stale states look intentional.
- Accessibility: keyboard completion, visible focus, focus return, names/roles, target size, contrast, zoom, and non-color communication.
- Anti-slop: reject interchangeable gradients, card grids without hierarchy, ornamental badges, excessive pills, fake metrics, and reference averaging.
- Register drift: flag brand pages that collapse into generic product chrome and product screens that import marketing spectacle, display labels, decorative motion, or surprising standard controls.

Record the exact rule and evidence for every design finding. Severity measures user/product impact; confidence measures strength of evidence.
