# Picker template

Use only for genuine design or behavior forks that repository authorities do not already decide.

```markdown
## <decision>

Evidence: <production observation + reference lock + governing principle>

1. <Option A> — Recommended. <rationale>. Tradeoff: <one sentence>.
2. <Option B> — <shape>. Tradeoff: <one sentence>.
3. <Option C, only when distinct> — <shape>. Tradeoff: <one sentence>.
```

Offer two to four distinct options, exactly one evidence-backed recommendation, and one tradeoff sentence each. Never auto-lock the choice or encode it as accepted in an ADR.
