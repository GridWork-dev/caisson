# Support

This repository is a **read-only public mirror** (see [CONTRIBUTING.md](CONTRIBUTING.md)).

## Get help

- **Discord** — the fastest way to reach us, and where the docs support bot answers
  questions in real time. Linked from [caisson.sh](https://caisson.sh).
- **Docs** — [caisson.sh/docs](https://caisson.sh/docs).
- **Bug reports and questions about the open base** — open an issue on this repository's
  tracker (package name, version, and a minimal reproduction — see
  [CONTRIBUTING.md](CONTRIBUTING.md)).
- **Commercial bundles, licensing, or billing** — [caisson.sh](https://caisson.sh) or email
  admin@caisson.sh.
- **Vulnerability report** — see [SECURITY.md](SECURITY.md), do not open a public issue.
