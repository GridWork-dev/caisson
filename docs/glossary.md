# Glossary

Caisson's domain vocabulary in one place: the terms that recur across `specs/`,
`knowledge/decisions/`, the package READMEs, and `docs/state/decisions-and-forks.md`.
Each entry is a short synthesized definition plus a pointer to the canonical owner.

**This file owns the catalog, not the facts.** The canonical source of every term stays
`specs/` + `knowledge/decisions/` (and, for live state, the board). On any conflict, the
owning ADR/spec wins. ASCII punctuation throughout; concatenation shown as `a + b` and
the envelope as `[a, b, ...]` to stay table-safe (the real notation uses bar separators).

Current build status (machine-checked, per package): [`docs/build-state.md`](build-state.md).

## Terms

| Term                                    | Definition                                                                                                                                                                                                                                                                                                                                                                                                      | Owner                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **AAD** (additional authenticated data) | Context bound into every `field-crypto` AES-256-GCM seal so a ciphertext cannot be moved between tenants, columns, or rows. Base binding is `tenant_id + key_version + column`; the SOC2/HIPAA path adds the row id via `encryptField(..., rowId)`.                                                                                                                                                             | [ADR-0045](../knowledge/decisions/ADR-0045-field-crypto-aead-cipher.md), [ADR-0055](../knowledge/decisions/ADR-0055-field-crypto-cryptoshred-and-row-aad.md), `packages/field-crypto/`                                                                                                                                               |
| **AeadCipher seam**                     | The pluggable authenticated-cipher interface `field-crypto` encrypts through. Default is zero-dependency AES-256-GCM via `node:crypto` (FIPS-approved); an alternate cipher is a drop-in without touching callers.                                                                                                                                                                                              | [ADR-0045](../knowledge/decisions/ADR-0045-field-crypto-aead-cipher.md), `packages/field-crypto/`                                                                                                                                                                                                                                    |
| **Audit chain**                         | Per-tenant append-only SHA-256 hash chain of evidence entries. Every append mints a fresh length-keyed write-once WORM anchor, so tamper, tail-truncation, and wholesale rewrite are all detectable via `verifyChain(entries, anchor)`.                                                                                                                                                                         | [ADR-0006](../knowledge/decisions/ADR-0006-worm-audit-chain-field-crypto.md), [ADR-0052](../knowledge/decisions/ADR-0052-audit-chain-anchor-persistence.md), `packages/audit-worm/`                                                                                                                                                  |
| **Base substrate**                      | The base-tier packages every edition composes over: `kernel`, `tenancy-rls`, `field-crypto`, `auth`, `billing`, `credits` (plus `ai-config`, `mcp-server`, `ui`, `jobs`, `email`). The genuinely-built core today.                                                                                                                                                                                              | [specs/01-architecture.md](../specs/01-architecture.md), [ADR-0003](../knowledge/decisions/ADR-0003-composable-package-base-split.md)                                                                                                                                                                                                |
| **Buyer MCP**                           | The shipped, auth-gated MCP server a buyer's coding agent uses to understand the codebase and drive `create-caisson`. Read-mostly and entitlement-scoped; its one write surface (generation) is credit-gated and validated against the registry allowlist.                                                                                                                                                      | [ADR-0008](../knowledge/decisions/ADR-0008-buyer-mcp-server-auth.md), [ADR-0076](../knowledge/decisions/ADR-0076-buyer-mcp-extensibility.md), `packages/mcp-server/`                                                                                                                                                                 |
| **Ciphertext envelope**                 | The self-describing binary layout `field-crypto` stores per encrypted value: `[ver, alg, key_version, nonce, ciphertext, tag]`, base64 into a `text` column. Decrypt reads ver/alg/key-version from the value itself, so rotation and cipher migration need no out-of-band metadata.                                                                                                                            | [ADR-0046](../knowledge/decisions/ADR-0046-ciphertext-envelope-format.md), `packages/field-crypto/`                                                                                                                                                                                                                                  |
| **Codegen credit**                      | The credit debited per `create-caisson` generation, the metered monetization of the Option-C generator. Debited before any file write (`eventType: "codegen_debit"`); a short balance returns 402 with nothing written; the same `idempotency_key` debits once.                                                                                                                                                 | [ADR-0004](../knowledge/decisions/ADR-0004-generator-registry-codegen-credits.md), [ADR-0049](../knowledge/decisions/ADR-0049-codegen-credit-debit-point.md), `packages/cli/`                                                                                                                                                        |
| **Composable composition**              | The architecture law (Option C): an edition is a composition of base packages plus vertical logic, never a fork, and a package never depends "up" on an edition (strictly down-only).                                                                                                                                                                                                                           | [ADR-0003](../knowledge/decisions/ADR-0003-composable-package-base-split.md), [specs/01-architecture.md](../specs/01-architecture.md)                                                                                                                                                                                                |
| **Credit / wallet / ledger**            | Money and usage as **integer** credits (never floats). A `credit_wallet` holds an integer balance derived from an append-only `credit_event` ledger of grants and debits; idempotency is DB-anchored.                                                                                                                                                                                                           | [ADR-0007](../knowledge/decisions/ADR-0007-credit-metering-model.md), [ADR-0024](../knowledge/decisions/ADR-0024-credit-idempotency-index.md), `packages/credits/`                                                                                                                                                                   |
| **Crypto-shred**                        | GDPR Art.17 erasure: request destruction of a tenant's KMS-held key-encryption key so its wrapped data key and ciphertext become unrecoverable once the provider proves destruction is irreversible. A soft-delete receipt remains recoverable. The audit chain commits to ciphertext, so shredding the key does not break chain verification.                                                                  | [ADR-0055](../knowledge/decisions/ADR-0055-field-crypto-cryptoshred-and-row-aad.md), `packages/field-crypto/src/crypto-shred.ts`                                                                                                                                                                                                     |
| **Debit-before-spend**                  | The credit invariant: debit the wallet before performing the metered work; insufficient balance returns HTTP **402** and the work never runs. Enforced inside `withTenant` for generation.                                                                                                                                                                                                                      | [ADR-0007](../knowledge/decisions/ADR-0007-credit-metering-model.md), [ADR-0019](../knowledge/decisions/ADR-0019-error-model.md), `packages/credits/`                                                                                                                                                                                |
| **Edition** (legacy)                    | The pre-2026-07-06 sellable product unit: **Base**, **Compliance** (hero), **AI Production Kit**, **Local-first AI**, **Agentic-Dev**. **DISSOLVED into Bundle** (see below) by the catalog rework (`ADR-0257`/`ADR-0258`, 2026-07-06). Legacy edition ids (`compliance`, `ai-kit`, `local-ai`, `agent-dev`) still resolve forever through the single alias point, so pre-dissolution tokens/links never break. | [ADR-0257](../knowledge/decisions/ADR-0257-catalog-rework-spec-locks.md), [ADR-0258](../knowledge/decisions/ADR-0258-catalog-pricing-consequence-locks.md), [specs/00-product-spec.md](../specs/00-product-spec.md)                                                                                                                  |
| **Bundle**                              | The current sellable, composed product unit on top of the base — supersedes **Edition** (`ADR-0257`/`ADR-0258`, 2026-07-06): six bundles — **Compliance** $1,649, **AI-Production** $739, **Local-first** $629, **Agentic-Dev** $329, **Provenance** $399 (net-new), **Everything** $2,259 (full catalog). Buying one grants a curated module set; every member module also sells à la carte.                   | [ADR-0257](../knowledge/decisions/ADR-0257-catalog-rework-spec-locks.md), [ADR-0383](../knowledge/decisions/ADR-0383-oscal-spine-sku-and-compliance-reprice.md), [ADR-0386](../knowledge/decisions/ADR-0386-everything-reprice-release-sequencing-and-wave-force-push.md), [docs/state/package-catalog.md](state/package-catalog.md) |
| **Entitlement / entitlement graph**     | An **entitlement** is what an account owns (edition, module, bundle, or subscription). The **entitlement graph** is the registry-derived membership resolver that expands an edition/bundle purchase into its member-module slug set at the gate; the registry is the source of truth.                                                                                                                          | [ADR-0071](../knowledge/decisions/ADR-0071-entitlement-expansion-registry-graph.md), `registry/`, `packages/license-verify/`                                                                                                                                                                                                         |
| **Evidence pack**                       | The Compliance edition's deliverable: a deterministic, golden-fixturable SOC2/HIPAA evidence bundle (RLS / WORM / chain collectors), per-tenant Ed25519-signed over a canonical manifest plus chain anchor, with a "flag, never guess" rule on missing evidence.                                                                                                                                                | [ADR-0056](../knowledge/decisions/ADR-0056-evidence-pack-signing.md), [ADR-0058](../knowledge/decisions/ADR-0058-evidence-pack-format-determinism.md), `packages/compliance/src/evidence/`                                                                                                                                           |
| **Fail-closed RLS**                     | Multi-tenant isolation where a missing tenant filter denies rather than leaks: Postgres FORCE row-level security keyed by `SET LOCAL` underneath the app filter, with a schema test. Tenancy denial returns 404 (no existence leak).                                                                                                                                                                            | [ADR-0005](../knowledge/decisions/ADR-0005-fail-closed-rls-tenancy.md), [ADR-0019](../knowledge/decisions/ADR-0019-error-model.md), `packages/tenancy-rls/`                                                                                                                                                                          |
| **field-crypto**                        | The base package giving per-tenant authenticated field encryption: HKDF-derived keys for dev/self-hosting or request-scoped KMS envelope encryption for hosted production, AES-256-GCM behind `AeadCipher`, a versioned envelope, rotation, and a pluggable `FieldKeyProvider`. The encryption boundary equals the RLS tenant boundary.                                                                         | [ADR-0043](../knowledge/decisions/ADR-0043-field-crypto-per-tenant-keys.md), [ADR-0045](../knowledge/decisions/ADR-0045-field-crypto-aead-cipher.md), [ADR-0046](../knowledge/decisions/ADR-0046-ciphertext-envelope-format.md), `packages/field-crypto/`                                                                            |
| **FieldKeyProvider (KMS port)**         | The `field-crypto` seam that yields a tenant key: `DerivedKeyProvider` is the zero-infrastructure dev/self-hosted path; `KmsKeyProvider` drives shipped AWS, GCP, or Azure clients. Caisson's hosted site binds Azure-backed historical keys per request and zeroizes them at exit.                                                                                                                             | [ADR-0043](../knowledge/decisions/ADR-0043-field-crypto-per-tenant-keys.md), [ADR-0389](../knowledge/decisions/ADR-0389-request-scoped-prefetch-all-kms-context.md), `packages/field-crypto/src/kms.ts`                                                                                                                              |
| **Generator / create-caisson**          | The `cli` that composes a tailored buyer repo from the versioned registry (Option C): Zod-`.strict()` selection, registry-allowlist validation **before** any path or subprocess, deterministic in-repo template copy + token/JSON-merge (no network), credit-metered. Full P5 disk materialization is a deferred seam.                                                                                         | [ADR-0004](../knowledge/decisions/ADR-0004-generator-registry-codegen-credits.md), [ADR-0048](../knowledge/decisions/ADR-0048-generator-engine.md), `packages/cli/`                                                                                                                                                                  |
| **Golden-file harness**                 | The regression gate: canonical fixtures (the audit anchor, the generated file set, the evidence pack) checked into `__golden__/` and asserted by `bun test`. Re-bless intentionally with `BLESS=1`. Required before any compliance logic.                                                                                                                                                                       | [ADR-0013](../knowledge/decisions/ADR-0013-testing-golden-file-harness.md), `tooling/testing/`, e.g. `packages/audit-worm/src/__golden__/`                                                                                                                                                                                           |
| **Manifest attestation**                | The proof, recorded per published version in `registry/ledger.jsonl` (`gateAttestation`, e.g. `ci-0001@<sha>`), that the standards gate passed in CI for that version. The gated publish flow is the one ingress; nothing enters the index un-attested.                                                                                                                                                         | [ADR-0021](../knowledge/decisions/ADR-0021-registry-publish-pipeline.md), [ADR-0069](../knowledge/decisions/ADR-0069-publish-flow-credential-backfill.md), `registry/ledger.jsonl`                                                                                                                                                   |
| **Module / package**                    | An independently sellable, independently versioned `@caisson-sh/*` package built to the one `tooling/` standard. The unit of a-la-carte commerce and of registry publication.                                                                                                                                                                                                                                   | [ADR-0001](../knowledge/decisions/ADR-0001-monorepo-tooling.md), [ADR-0003](../knowledge/decisions/ADR-0003-composable-package-base-split.md), `packages/`                                                                                                                                                                           |
| **Module manifest**                     | The typed (canonical Zod) declaration every module ships: id, version, kind, tier, price, license, dependencies, entry, golden, stability, description. Consumed and enforced by the standards gate and the registry index.                                                                                                                                                                                     | [ADR-0020](../knowledge/decisions/ADR-0020-module-manifest-authoring.md), `registry/schema/module-manifest.ts`                                                                                                                                                                                                                       |
| **Pro-private firewall**                | The binding build rule: nothing from the pro-private `media-pipeline` repo may seed any package, patterns and ideas only, never implementation. The harvestable license kit is taken from the PUBLIC `tessera` instead.                                                                                                                                                                                         | [CLAUDE.md](../CLAUDE.md), [specs/00-product-spec.md](../specs/00-product-spec.md)                                                                                                                                                                                                                                                   |
| **Registry**                            | The **catalog** (an index, not a source mirror) that the `cli`, the buyer agent, and the docs all read. `ledger.jsonl` is the git-tracked source of truth; CI builds `index.json` from it (parse-or-throw allowlist); a Cloudflare Worker read seam is deployed LIVE (caisson-registry.broken-wood-97a9.workers.dev; ADR-0047 seam → live).                                                                     | [ADR-0004](../knowledge/decisions/ADR-0004-generator-registry-codegen-credits.md), [ADR-0021](../knowledge/decisions/ADR-0021-registry-publish-pipeline.md), [ADR-0047](../knowledge/decisions/ADR-0047-registry-readpath-worker-seam.md), `registry/`                                                                               |
| **Standards gate**                      | The single lint-policy/tsconfig/test + lint-gate source (`tooling/`) every package ships through. In CI it is one of 5 unconditional required checks and the **sole registry ingress**: no gate pass, no publish.                                                                                                                                                                                               | [ADR-0016](../knowledge/decisions/ADR-0016-ci-cd-standards-gate.md), [ADR-0022](../knowledge/decisions/ADR-0022-import-boundary-lint-gates.md), `tooling/standards-gate/`                                                                                                                                                            |
| **WORM**                                | Write-once-read-many evidentiary storage via the `ArtifactStore` port (S3 Object-Lock in prod, local/test doubles in CI). GOVERNANCE retention default with a guarded irreversible opt-in to COMPLIANCE, per-tenant key-prefix isolation, and a 6-7yr retention floor. Anchors the audit chain.                                                                                                                 | [ADR-0051](../knowledge/decisions/ADR-0051-worm-objectlock-retention-mode.md), [ADR-0054](../knowledge/decisions/ADR-0054-worm-artifactstore-port.md), `packages/audit-worm/`                                                                                                                                                        |
| **withTenant**                          | The sole entry point that opens a tenant-scoped RLS transaction (sets `SET LOCAL` for the tenant, runs the callback inside it). All tenant-bound work, including credit debits and generation, runs inside it.                                                                                                                                                                                                  | [ADR-0015](../knowledge/decisions/ADR-0015-auth-session-rls-seam.md), [ADR-0005](../knowledge/decisions/ADR-0005-fail-closed-rls-tenancy.md), `packages/tenancy-rls/src/rls.ts`                                                                                                                                                      |
